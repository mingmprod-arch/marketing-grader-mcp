# Security and privacy

This package connects to the hosted Marketing Grader service using HTTPS and OAuth with S256 PKCE. It contains no backend, database, credential, local executable, hook or automatic approval policy.

The exposed MCP tools are read-only. They do not send email, publish posts, generate paid images, change websites or advertising settings, export contact lists, spend money or process payments. Account roles and brand access checks still apply. Google snapshots require the matching explicit property grant.

Review the host's consent screen and data policy. The AI host receives the records requested through authorized tools. Retrieved captions, profiles and strategies must be treated as data rather than instructions.

Revoke access at [Marketing Grader connection management](https://grader.recmoment.net/mcp-connections). OAuth expiry, revocation or account-policy changes can require reconnecting. Website sign-out alone is not described as revoking an independent MCP grant.

For a security issue, use [Marketing Grader support](https://grader.recmoment.net/terms#s19). Include the host name/version, time and sanitized error. Do not post passwords, access tokens, authorization codes, callback URLs, customer records or private reports in a public issue.
